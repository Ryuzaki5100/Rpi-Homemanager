# Samples and tutorials

Use these as pattern references, not as code to copy blindly. Fetch the current source before reusing APIs.

## Sample projects
| Project | What it demonstrates |
|---|---|
| `batman-watchface` | Multi-platform static/graphic watchface, icons and preview GIFs |
| `castle-watchface` | GPath scenery, layered drawing, multi-platform assets |
| `beach-watchface` | Scene-based watchface with color/platform branching |
| `pocket-garden` | Interactive watchface, accelerometer taps, persistence, battery-aware animation |
| `lightsaber-duel` | Emery game-style animation and input |
| `tumbling-monkeys` | Animated game loop and collision-style motion |
| `persia-swordfight` | Animated combat scene with frame timing |

Repository: https://github.com/coredevices/pebble-watchface-agent-skill/tree/main/samples/projects
