# Store listing copy

## Title
Short, recognizable, no version numbers.

## Description
- 2–4 short paragraphs.
- Lead with the watch experience, not implementation details.
- Mention target watches/platforms.
- Mention settings/phone requirements (e.g., "weather requires the phone app").
- Avoid unverifiable claims ("best", "fastest").

## Category
Pick the closest official category; do not invent one.

## Release notes
- Bullet list of user-visible changes.
- Note fixes and known limitations.

## Screenshots/GIF
- Use verified screenshots only.
- Show the default state and one key interaction/animation.
- Do not include personal data or debug overlays.
